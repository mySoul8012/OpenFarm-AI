
# OpenFarm AI
### 基于米家生态的企业级 AI 智能农业水培系统

> 让农业智能化，让种植自动化，让每个空间都成为智能农场。

OpenFarm AI 是一个面向家庭、企业、实验室、学校及商业农业场景的开源智能水培项目。项目以小米米家生态和 Home Assistant 为智能设备管理基础，结合自主研发的农业控制器、PCB 电路板、环境传感器、供水系统、加热系统及 AI 技术，构建一套模块化、自动化、可扩展的智能农业基础设施。

项目不仅关注植物种植本身，也关注水、电、温度、光照、营养液、环境监测和设备控制等完整农业基础设施，致力于打造一套可持续扩展的智能农业平台。

---

## 1. 项目目标

- 建立基于米家生态的智能农业设备管理系统。
- 实现水培环境的自动监测与自动控制。
- 自主设计农业控制器、电路板及 PCB。
- 建立模块化供水、循环、排水及营养液管理系统。
- 实现温度、湿度、水位、pH、EC 等参数监测。
- 集成补光、加热、通风、灌溉等自动化设备。
- 引入 AI 视觉识别和智能种植管理能力。
- 提供开放的硬件设计、软件代码、设备接口和部署方案。

## 3. 硬件系统

### 3.1 主控电路板与 PCB 设计

自主设计 OpenFarm AI 农业控制器，负责传感器采集、设备控制和通信。

计划包含：

- ESP32 主控模块。
- 传感器信号采集电路。
- pH 和 EC 传感器接口。
- 水温、空气温湿度传感器接口。
- 水位及液位检测接口。
- 水泵、风扇、电磁阀控制接口。
- 补光灯及加热设备控制接口。
- 继电器或 MOSFET 驱动模块。
- 电源管理及过流保护。
- Wi-Fi、蓝牙及 MQTT 通信支持。
- 状态指示灯、调试接口及扩展接口。

PCB 设计计划公开：

- 原理图（Schematic）。
- PCB Layout。
- Gerber 制造文件。
- BOM 元器件清单。
- 3D PCB 模型。
- 接线图及硬件说明。
- 固件及烧录说明。

### 3.2 传感器系统

用于持续监测植物生长环境和水培系统运行状态。

| 监测项目 | 主要用途 |
|---|---|
| 空气温度 | 监测种植环境温度 |
| 空气湿度 | 监测空气湿度 |
| 水温 | 监测营养液温度 |
| pH | 监测营养液酸碱度 |
| EC | 监测营养液电导率 |
| 水位 | 监测水箱液位 |
| 光照强度 | 调节植物补光 |
| 水流状态 | 监测水循环运行 |
| 漏水检测 | 监测管路及设备漏水 |
| 摄像头 | 植物生长图像采集 |

### 3.3 水培与供水系统

设计模块化水培基础设施，支持不同规模的种植架和栽培设备。

主要设施：

- 原水储水箱。
- 营养液混合箱。
- 水培栽培槽及种植塔。
- PVC、PE 或食品接触级管路。
- 供水管、回水管及排水管。
- 循环水泵及供水泵。
- 电磁阀及流量控制装置。
- 过滤器及管路接头。
- 水位检测及防溢流设施。
- 自动补水及营养液循环系统。

系统支持循环供水、定时灌溉、自动排水及异常报警。

### 3.4 温度控制与加热设施

根据不同植物和种植环境配置温度控制设备。

计划支持：

- 电热毯及育苗加热垫。
- 水箱及营养液加热器。
- 根系区域加热设施。
- 温度传感器及温控模块。
- 保温棉及隔热材料。
- 环境通风及散热风扇。
- 自动温度控制与超温报警。

加热设备应使用符合当地规范的产品，并配置独立温控、过温保护及漏电保护。电热毯等设备需与水源隔离，避免直接接触水体。

### 3.5 光照与环境控制

- LED 全光谱植物生长灯。
- 自动补光控制。
- 光照强度监测。
- 自动通风系统。
- 空气循环风扇。
- 湿度控制设备。
- 温湿度联动控制。

## 4. 软件与智能平台

### Home Assistant

作为统一设备管理和自动化平台，接入米家设备及自主研发的农业硬件。

### 米家生态

通过支持的米家设备和 Home Assistant 集成，实现温湿度监测、智能插座控制及其他设备联动。

说明：米家设备接入 Home Assistant，不等于自研硬件已经获得米家 App 原生接入能力。后续可根据小米 IoT 平台的接入条件探索原生生态集成。

### ESP32 / ESPHome

用于农业控制器固件开发、传感器数据采集和执行器控制。

### MQTT

用于农业设备、Home Assistant 和 AI 平台之间的数据通信。

### AI 智能系统

计划开发：

- AI 植物生长状态识别。
- 植物病害及异常识别。
- 生长周期记录与分析。
- pH、EC 及环境数据分析。
- 智能补光和温度调节建议。
- 自动灌溉及营养液管理策略。
- AI 种植助手及设备控制 Agent。

AI 自动控制将结合设备权限、运行规则和安全阈值，避免模型直接执行不受约束的设备操作。

## 6. 安全设计

农业设施涉及水、电、加热和自动化设备，系统设计需要考虑：

- 强弱电分离。
- 电源过流、短路及过温保护。
- 漏电保护和可靠接地。
- 水泵空转保护。
- 水箱溢流及缺水保护。
- 管路漏水检测。
- 加热设备独立温控。
- 设备故障报警及紧急停止。
- 关键设备支持手动控制。
- 传感器异常时进入安全状态。

涉及市电的 PCB、继电器及控制箱设计，应由具备相应资质的人员进行设计、安装和验证。

## 8. 研发路线

**第一阶段：基础水培设施**

- 完成水箱、管路、种植架及循环系统设计。
- 完成 ESP32 基础控制器。
- 接入温湿度、水温及水位传感器。

**第二阶段：智能设备联动**

- 部署 Home Assistant。
- 接入米家智能设备。
- 实现水泵、补光灯和加热设备自动控制。
- 建立设备监控 Dashboard。

**第三阶段：农业监测与自动化**

- 接入 pH、EC 传感器。
- 实现营养液监测及自动补水。
- 完成温度、光照和灌溉自动化策略。

**第四阶段：AI 智能农业**

- 建立植物图像采集系统。
- 开发 AI 植物识别及生长分析。
- 开发 AI 种植助手。
- 实现受安全规则约束的 AI 自动控制。

**第五阶段：企业级扩展**

- 支持多种植区域管理。
- 支持多套水培设备集中控制。
- 建立数据记录、报表及告警系统。
- 支持远程运维和设备状态监控。
- 探索商业化农业设备及解决方案。

## 9. 商业化方向

OpenFarm AI 采用开放平台与商业硬件相结合的模式。

- 智能水培设备及种植系统。
- ESP32 农业控制器及 PCB 模块。
- pH、EC 和环境监测模块。
- 自动营养液管理设备。
- AI 植物识别及种植管理服务。
- 学校、办公室及企业农业解决方案。
- 水培耗材、营养液及替换配件。

## 11. 项目愿景

OpenFarm AI 希望将智能家居、人工智能、自动化控制和现代农业结合起来，建立一套开放、模块化、可复制、可扩展的智能农业系统。

从家庭阳台到室内农场，从单套水培设备到企业级农业设施，让农业设备具备感知、分析、决策和自动执行能力。
